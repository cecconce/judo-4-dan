# judo-4-dan

Raccolta di studio per l'esame di 4° dan di judo FIJLKAM — Pierluigi Ceccon.

Sito statico (GitHub Pages), pensato per lo smartphone: menu a scorrimento, tema chiaro/scuro, ricerca nel testo e uso offline (PWA, "Aggiungi a schermata Home").

Sito: https://cecconce.github.io/judo-4-dan/

## Aggiornare i contenuti
1. Modificare i file in `content/*.md`
2. Eseguire `python3 build.py` (richiede `pip install markdown`)
3. Caricare le modifiche su GitHub

Strumento di studio personale: per date, requisiti e regolamenti fanno fede le circolari FIJLKAM dell'anno in corso.
